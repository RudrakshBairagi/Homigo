Recipe Explorer 

A dynamic, front-end web application that allows users to discover and explore random food recipes. This project fetches real-time culinary data and displays it in clean, easy-to-read interactive cards.

Tech Stack:

This project is built using modern web development technologies:
1. React.js: For building the interactive user interface and managing component state.
2. JavaScript (ES6+): The core logic and API data fetching.
3. HTML5: For structuring the web application.
4. CSS3: For styling the grid layout and recipe cards.
